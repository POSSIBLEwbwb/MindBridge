# 解决引用信息补全导致参考资料乱序问题

## 问题

RAG 回答需要带参考资料。系统在召回片段后，会补全父分段、兄弟分段或上下文片段。但补全动作如果不保留原始相关性顺序，就会导致最终参考资料乱序。

表现是：最相关的片段本来排在前面，补全文本后反而被打散。

## 解决思路

引用补全只补内容，不改排序主依据：

- 保留原始召回分数和排序位置。
- 补全父子片段时记录来源关系。
- 最终参考资料仍按检索和重排后的相关性顺序输出。

## 产品价值

用户看到的引用顺序更可信，前几个参考资料就是最值得看的来源，减少“答案看起来对，但引用顺序混乱”的体验问题。

## 面试讲法

> 我们做父子分段补全时发现一个问题：补全能让上下文更完整，但也可能打乱原始相关性顺序。所以后面改成补全文本不改变排序主依据，引用仍然按召回和重排后的相关性输出。
