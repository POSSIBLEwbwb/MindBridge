# 通过修改 ground truth 解决评测偏差

## 问题

RAG 评测依赖标准答案。如果 ground truth 写得太窄、太旧，或者和业务口径不一致，系统明明回答合理，也可能被评测为错误。

## 解决思路

对评测集中的标准答案做校准：

- 检查标准答案是否和文档内容一致。
- 对同义表达做适当兼容。
- 删除过时或明显不合理的标注。
- 保留人工确认过的业务口径。

## 产品价值

评测集本身也是产品资产。只有标准答案可靠，指标变化才有意义。

## 面试讲法

> RAG 评测不是把问题丢给工具就完事。我们发现有些 bad case 不是系统错，而是标准答案标得不准。所以会反查原文和业务口径，把 ground truth 校准后再看指标。
