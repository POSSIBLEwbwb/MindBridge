# 解决 MinerU 不支持多级标题解析的问题

## 问题

PDF 经过 MinerU 解析成 Markdown 后，标题层级可能不完整。原本应该是一级标题、二级标题、三级标题的内容，被解析成普通文本或同级标题。

这会影响后续按标题切分，因为系统无法判断章节边界，容易把不同主题的内容切到同一个 chunk 里。

## 解决思路

在文档预处理阶段，对 Markdown 标题结构做二次修正：

- 识别章节编号、标题样式和上下文位置。
- 补齐缺失的标题层级。
- 尽量保持标题、正文、图片和表格的相对顺序。

## 产品价值

标题结构变清楚以后，后续分段可以更贴近原文语义。召回时命中的片段更完整，也更容易带出所在章节信息。

## 面试讲法

> MinerU 解决的是 PDF 解析问题，但它解析出来的 Markdown 不一定天然适合 RAG。我们遇到过多级标题丢失的问题，所以在入库前做了一层结构修正，让分段更像按真实章节来切，而不是机械按字数切。
