# 通过优化系统提示词提升答案正确性

## 问题

检索结果正确，不代表模型一定会正确回答。模型可能过度发挥、补充上下文里没有的信息，或者没有明确说明“不确定”。

## 解决思路

优化系统提示词，明确约束模型行为：

- 优先基于召回上下文回答。
- 上下文不足时不要编造。
- 区分事实回答、推断回答和无法回答。
- 输出结构尽量稳定，方便前端展示和后续评测。

## 产品价值

提示词优化不是为了让回答更“会说”，而是为了让回答更受控、更符合业务口径。

## 面试讲法

> RAG 里 Prompt 的作用是给模型立规矩。我们不是让模型自由发挥，而是要求它尽量引用上下文、缺信息就说明不足，这样能明显减少看起来很流畅但事实不可靠的回答。
