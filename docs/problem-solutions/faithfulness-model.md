# 通过换模型解决忠诚度低的问题

## 问题

有些模型语言能力强，但在 RAG 场景下不一定忠实于上下文。它可能检索到了正确资料，却在生成时加入自己的推测。

这会导致 Faithfulness 分数低，也就是回答没有严格基于上下文。

## 解决思路

对不同生成模型做对比，选择更适合 RAG 的模型：

- 看回答是否紧贴上下文。
- 看是否容易补充未检索到的信息。
- 看中文表达和业务口径是否稳定。

## 产品价值

模型选择不只看通用能力，还要看它在当前链路里的表现。RAG 场景更看重忠实、稳定、可控。

## 面试讲法

> 我们换模型不是追新，而是看 RAG 指标。有的模型很会说，但容易脱离上下文。我们更关注忠实度，也就是它有没有严格根据检索结果回答。
